🚀 Industrial Machinery Predictive Maintenance

📌 Overview

A Machine Learning-based predictive maintenance system that analyzes industrial machinery sensor data to predict potential failures before they occur. The solution helps reduce downtime, optimize maintenance schedules, and improve operational efficiency.

 🎯 Key Features

* Predicts machine failures before breakdowns occur
* Classifies multiple failure types:

  * Tool Wear Failure
  * Heat Dissipation Failure
  * Power Failure
  * Overstrain Failure
  * Random Failure
* Real-time prediction using deployed cloud services
* Supports proactive and data-driven maintenance
* Reduces maintenance costs and production losses

🛠️ Technologies Used

* **IBM Cloud Lite**
* **IBM Watsonx.ai (AutoAI)**
* **IBM Watson Machine Learning**
* **Python, Pandas, NumPy, Scikit-learn**
* **IBM Cloud Object Storage**
* **REST API Deployment**

 🤖 Machine Learning Workflow

* Data Collection (Kaggle Predictive Maintenance Dataset)
* Data Preprocessing & Feature Engineering
* Exploratory Data Analysis (EDA)
* Model Training using AutoAI
* Model Evaluation & Selection
* Cloud Deployment
* Real-Time Failure Prediction

📊 Algorithm Used

**Random Forest Classifier** *(Best Performing Model)*

* High prediction accuracy
* Handles large datasets efficiently
* Reduces overfitting
* Excellent multiclass classification performance
